# 使用手册 — IELTS Reading Lab

> 面向最终用户。2026-11-10。软件运行在 Windows 桌面（也可在浏览器里预览界面）。

## 1. 安装与启动

### 已打包应用（推荐，无需命令行）

桌面上有一个 **`IELTS Reading Lab.exe - 快捷方式.lnk`**——**双击它即可打开应用**，不需要命令行。它指向 `release\IELTS Reading Lab v2\IELTS Reading Lab.exe`（整个目录可拷贝到别处或分发，数据仍存当前用户的 `%APPDATA%\ielts-reading-lab`，与程序目录分离）。

打包应用位于 `release\IELTS Reading Lab v2\IELTS Reading Lab.exe`（整个目录可拷贝到任意位置或分发给别人，数据仍存在当前用户的 `%APPDATA%\ielts-reading-lab`，与程序目录分离）。

### 从源码运行（开发用）

需要 Node.js 22+ 与 npm。在项目目录执行：

```bash
npm install          # 首次，或依赖变更后
npm start            # 构建并打开桌面应用
```

也可以双击 `scripts/start-app.cmd`。只想在浏览器里看界面（数据存 localStorage，不互通）时用 `npm run dev:web`，然后访问 `http://127.0.0.1:5173`。

常见问题：从某些终端启动后没有窗口，是因为宿主注入了 `ELECTRON_RUN_AS_NODE=1`。桌面启动器与 `scripts/start-app.cmd` 都已自动清除它；手动执行请用 `ELECTRON_RUN_AS_NODE= npm start`。

## 2. 文章库

左侧导航「文章库」。首次启动自动内置 **100 篇原创 IELTS 风格练习文章**，每篇约 700–800 词，标题下显示来源说明。支持按标题/正文搜索。

- **导入自己的文章**：右侧「导入新文章」填标题与英文纯文本（≥40 字符）→「导入并开始阅读」。文章按空行分段、按 `. ! ?` 分句，标点完整保留。
- **内置内容说明**：这些是本项目原创合成文本，**不是官方真题**。真实雅思真题受版权保护，不能复制分发。内置文章的每句都附带中文译文和英文主谓宾；你自己导入的文章没有内置解析，会显示"本地保守解析"（只给结构提示，不硬判对错）。
- **文章更新**：内置语料升级时会自动刷新内容（保留创建时间）；你删除过的内置文章不会复活，自己导入的文章不受影响。

## 3. 阅读工作台

左侧导航选一篇文章进入。正文栏宽约 740 px，字号可在设置里调。

| 操作 | 结果 |
|---|---|
| **鼠标左键点击单词** | 弹出离线词典卡片：音标、中文释义、考试标签（雅思/四六级/考研/托福/牛津 3000/柯林斯星级）、词形还原（如 `better → good`） |
| 左键拖拽划选短语 | 同样弹出词卡（查询短语） |
| **鼠标右键点击句子** | 立即在右栏打开该句的解析，并**记录"答案已暴露"**（之后训练这句不再算无提示独立测评） |
| 键盘 `Enter`（焦点在句子上） | 与右键相同，打开解析 |
| `Esc` / 点击正文空白 | 关闭词卡 |

词库完全离线（ECDICT 派生 11,828 条），不联网、不花钱。生僻词或专有名词可能未收录，会如实提示而不是编造释义。

### 解析栏内容

右键点句后右侧显示：

- **结构 / Structure**：英文原句里的 Subject（主语）、Predicate（谓语）、Object（宾语），取自原句片段，不是中文翻译。
- **意群 / Chunks**：按语义切分的英文片段及作用标签。
- **语义 / Meaning**：整句中文参考译文。
- **词组 / Phrases**：句中出现的常见学术词组及语境义。
- **诊断目标 / Targets**：这句的可验证理解点。
- **可选追问 / Follow-ups**：自检问题。

解析栏底部有三个按钮：**进入引导训练**、**稍后复习 · 排入复测**、**收起解析栏**。

## 4. 引导训练（核心功能）

从解析栏底部点「进入引导训练」，进入同窗口专注模式。

1. 顶部显示目标句与邻近上下文；Level 0 不给任何提示。
2. 用**自己的中文**表达你对句子的理解——不需要写语法术语，自然表达即可。
3. 点「提交首次理解」。首次答案立即保存，之后不可覆盖。
4. 系统按证据给出渐进反馈：
   - **L0 无提示** → **L1 定位问题范围** → **L2 局部线索** → **L3 完整解析**。
   - 你可以随时请求更深入的提示或直接看完整解析，但一旦解锁 L3，这句就不再计为"独立正确"。
   - 重要局部错误且你有可能自行修正时，系统会给一次「提交二次表达」的机会。
5. 完成后可能给一条**同技能迁移题**（另一句英文）；可选做，不做也能退出。
6. 点「返回阅读」回到原文，滚动位置自动恢复。

判定原则：**合理简化不算错、没提到不等于不会、有歧义允许争议、缺少语法术语不扣分**。诊断只给证据和建议，是否通过由软件的教学规则决定。

## 5. 学习档案

左侧导航「学习档案」，四个页签：

| 页签 | 内容 |
|---|---|
| 能力观察 | 逐目标的能力记录（含提示暴露条件） |
| 复测队列 | 迁移题与稍后复习的 scheduled 复测任务，可标记"已复测" |
| 稍后复习 | 你在解析栏标记过的句子，可标记完成 |
| 训练会话 | 历史会话、作答、反馈与版本信息，可恢复 |

## 6. 设置

左侧导航「设置」。

### 6.1 第三方 API（可选）

默认**未启用**，软件完全离线工作（内置解析 + 离线查词 + 本地规则诊断）。若要接真实大模型：

1. 填 **Base URL**（OpenAI 兼容端点，如 `https://api.openai.com/v1`）、**模型名**、**API Key**。
2. 勾选费用确认 →「保存配置」。
3. 点「测试连接」（发送一次极小真实请求，可能产生微量费用）。
4. 点「启用诊断」。之后训练诊断会调用你选的模型。

「停用」或「清除密钥」立即回到零请求的离线状态。密钥用 Windows DPAPI 加密保存在主进程，**不进入界面回显、日志、数据库记录或导出文件**。注意：这是**独立计费的第三方 API**，与 ChatGPT Plus/Pro 订阅无关。

> 当前记录的端点 `https://moyuu.cc/v1` 实测返回 Cloudflare 503（服务暂时隔离），使用前请换可用端点。详见 `docs/DELIVERY.md` §8。

### 6.2 阅读与隐私

- **正文字号**：滑块调整阅读栏字号（0.85×–1.5×）。
- **学习历史个性化**：关闭后不再把历史观察附带到诊断上下文。
- **显示 Provider / 模型标识**：训练结果与诊断表注明来源。

### 6.3 数据管理

- 「导出数据」下载 JSON 备份（不含密钥）。
- 「删除全部数据」清空本地记录；内置文章会在下次启动重新出现，第三方 API 需重新配置。

## 7. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 启动后没有窗口 | 终端注入了 `ELECTRON_RUN_AS_NODE=1`；用 `scripts/start-app.cmd` 或 `ELECTRON_RUN_AS_NODE= npm start` |
| 浏览器预览里查词/解析正常但 API 连接失败 | 浏览器预览密钥仅内存保存，且可能受 CORS 限制；改用桌面应用 |
| API 报 401/403 | 密钥失效或权限不足；在设置里更新 Key |
| API 报 429 | 额度用尽；停止重试，换端点或等待 |
| API 报网络错误 | 端点不可达/超时；作答会被完整保留，可稍后重试 |
| 训练提交后显示"诊断失败" | 作答已保存，不会丢；检查 API 配置或回到离线兜底 |
| 浏览器预览 502 | 大文件热更新导致 Vite 挂掉，重跑 `npm run dev:web` |
| 内置文章没更新 | 语料版本升级时会自动刷新；确认已重启应用 |
| 生僻词查不到 | 词库只覆盖内置语料实词与考试高频词，会如实提示 |

## 8. 数据存在哪里

- 桌面应用：`%APPDATA%\ielts-reading-lab\reading-lab.sqlite`（文章、会话、作答、诊断、学习档案）+ 同目录 `api-credential.bin`（DPAPI 加密密钥）。
- 浏览器预览：浏览器 localStorage，与桌面数据**不互通**。

删除数据前请先导出备份。导出的 JSON 不含 API Key。
